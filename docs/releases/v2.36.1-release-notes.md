# v2.36.1 — Canonical methodology + shape-aware V2 sparse default

Sprint Option β: methodology pivot + V2 sparse attention graduation.

## Headlines

- **V2 cooperative-tensor sparse attention now activates transparently**
  for sparse-attention shapes with `qL × kL × D ≥ 2.15e9` (= 4096 × 4096
  × 128 work product). Users on M5+ see 1.95×–13.86× speedup vs
  SDPA+bias on FlashVSR-class workloads without any code or env-var
  changes.
- **Canonical Apple Silicon benchmark protocol** adopted for sub-1.5ms
  kernel measurement (`docs/methodology/canonical-protocol.md`). Resolves
  the sub-1ms variance issue surfaced in v2.36.0 V2-only re-bench.
- **Sub-1ms variance methodology thread CLOSED.** Two REGRESSION sprints
  + six-source web research convergence confirmed userspace P-state
  lock is unavailable on M5 Max. Option 4 (shape-aware default)
  activated via this release.

## What's new

### Shape-aware `decide_auto_version()` (the user-facing change)

```python
import mlx_mfa
from mlx_mfa import flash_attention_sparse

# Large shape: V2 fires transparently (was V1 in v2.36.0).
O = flash_attention_sparse(Q, K, V, block_mask)   # qL=kL=16384, D=128
# -> V2 kernel, 13.86× faster than SDPA+bias per canonical bench.

# Below threshold: V1 still default (no canonical-protocol data yet).
O = flash_attention_sparse(Q, K, V, block_mask)   # qL=kL=2048, D=128
# -> V1 kernel (conservative, no validation data for this regime).

# Override either way via env var (preserved from v2.35.0 contract).
# MFA_LCSA_KERNEL_VERSION=v2 forces V2 unconditionally.
# MFA_LCSA_KERNEL_VERSION=v1 forces V1 unconditionally.
```

The public function `mlx_mfa.lcsa_nax.decide_auto_version(density, qL,
kL, D)` exposes the routing decision for inspection.

### Methodology pivot

`docs/methodology/canonical-protocol.md` codifies the Apple Silicon
canonical benchmark methodology (10 warmup + 100 continuous timed
iterations, mx synchronisation inside loops, ratio analysis). Replaces
§4-strict cooldown protocol for sub-1.5ms kernels. §4-strict remains
canonical for ≥1.5ms kernels — see `CLAUDE_V6_NAX.md` §4.3 for selection
rule.

Six ecosystem sources cited (Apple Developer Forums, Feng et al. arXiv
2501.14925, MLX docs, WWDC25 Session 315, Draw Things MFA v2.5 NA, MLX
GitHub Discussion #1571) confirmed the methodology pivot is canonical
across the Apple Silicon ML community.

## Migration

| Pre-v2.36.1 env state | Post-v2.36.1 behaviour |
|---|---|
| `MFA_LCSA_KERNEL_VERSION` unset (v2.36.0 default) | Shape-aware default: V2 for `qL × kL × D ≥ 2.15e9`, V1 below |
| `MFA_LCSA_KERNEL_VERSION=v1` | V1 forced universally (unchanged) |
| `MFA_LCSA_KERNEL_VERSION=v2` | V2 forced universally (unchanged — power-user override preserved) |

No code changes required. No public API signatures changed. All Sprint
U auto-on-import hooks preserved.

## Unchanged

- v2.35.0 V2 kernel source code preserved.
- v2.36.0 auto-default infrastructure preserved (auto-on-import hooks,
  `flash_attention_sparse` → `sparse_attention_dispatch` routing,
  Conv3D NAX via `mx.conv_general` hook).
- All patchers (`patch_seedvr2_vae`, `patch_flashvsr_lcsa`,
  `patch_mlx_lm`) preserved as expert API.
